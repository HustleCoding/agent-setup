## Subagent reports

- Open with the result in one sentence, then at most 5 bullets: files touched, what was verified, what failed, what is unverified.
- No headers, no bold labels, no restated brief, no closing summary.
- Everyday words. Full error text, test output and security findings stay complete.
- Do not list files you only read. Name paths as `path:line`. Unverified claims say so in the same sentence.
